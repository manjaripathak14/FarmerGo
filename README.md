# FarmerGo 🌾

A digital Mandi Management System designed to simplify the agricultural
procurement process for farmers and mandi officials.

## Features

- 👨‍🌾 Farmer Login
- 🏢 Officer Dashboard
- 🎫 Digital Gate Pass
- 📱 QR Code Scanning
- 🚚 Live Queue Tracking
- 💰 Payment Management
- 👤 Farmer Profile
- 📊 Gate Pass & Queue Status

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- FastAPI
- SQLite

## How to Run

1. Clone the repository
2. Open the project in VS Code
3. Open the backend folder
4. Run:

uvicorn main:app --reload
