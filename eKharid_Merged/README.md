# 🌾 SIH Mandi Management System

A simple, beginner-friendly prototype built for Smart India Hackathon (SIH).
It lets **farmers** generate a digital gate pass, track their position in a
procurement queue, and view payments — and lets **officers** monitor and move
farmers through each procurement stage, including by scanning a QR code.

This is a **prototype**, not a production system. The code is kept
intentionally simple: plain FastAPI + SQLite backend, and plain
HTML/CSS/JavaScript frontend (no frameworks, no build tools).

## 2. Requirements

* Python 3.9 or newer
* Internet access the first time you run it (to install packages, and for
  the QR-scanner page which loads the `html5-qrcode` library from a CDN)

## 3. How to run it (step by step)

Open a terminal in the project's root folder (`SIH-Mandi-System/`).

### Step 1 — Install the backend dependencies

```bash
pip install -r requirements.txt
```

This installs FastAPI (our web framework), Uvicorn (the server that runs
it), Pydantic (data validation), and the `qrcode` + `pillow` libraries
(used to generate QR code images).

### Step 2 — Go into the backend folder

```bash
cd backend
```

### Step 3 — Database is already seeded (optional: reset it)

`backend/mandi.db` is already included in this project, pre-loaded with
demo farmers, an officer account, and storage-capacity records — so you
can log in and demo the app immediately, with no extra setup step.

If you ever want to reset the data back to this original demo state
(for example, after testing gate passes and payments), just run:

```bash
python seed_data.py
```

This wipes and re-fills `mandi.db` with the same fresh demo data.

### Step 4 — Start the server

```bash
uvicorn main:app --reload
```

### Step 5 — Open the app

Go to:

```
http://127.0.0.1:8000
```

You'll land on the login page, where you can choose **Farmer Login** or
**Officer Login**.

The interactive API documentation (auto-generated by FastAPI) is available at:

```
http://127.0.0.1:8000/docs
```

This is useful for testing any endpoint directly, and for demonstrating
the backend during your SIH presentation.

   payment and generate a receipt.

## 6. Notes on prototype simplifications

This project intentionally keeps things simple, as required for an SIH
prototype:

* **Authentication** — Farmers log in with name + mobile (matched against
  existing records). Officers log in with a username/password stored in
  plain text in the database. **A real system must hash passwords and use
  a proper session/JWT-based authentication system.**
* **Payments** — Fully simulated. No real payment gateway is integrated.
* **Database** — SQLite, a single file (`mandi.db`), good enough for a
  local demo. A production system would use a managed database.
* **QR code generation/scanning** — Uses existing libraries (`qrcode` on
  the backend, `html5-qrcode` on the frontend) rather than custom logic.
* **Real-time updates** — Simple polling (checking every few seconds)
  instead of WebSockets, which is enough for a demo.

## 7. Troubleshooting

* **"No module named fastapi"** → Run `pip install -r requirements.txt`
  from the project's root folder first.
* **Camera scanner doesn't open** → Some browsers only allow camera
  access over `https://` or `localhost`. Since we're running on
  `127.0.0.1`, this usually works fine in Chrome/Edge — but if the
  camera still doesn't start, just use the **manual Gate Pass ID entry
  box** on the scanner page instead.
* **"Storage capacity is not available"** → Try a different date, or a
  smaller estimated weight. Demo date `2026-09-17` is set up to already
  be almost full, so you can use it to show this error message.
